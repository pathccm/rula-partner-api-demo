# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in this repository — including the demo code, API client, or OpenAPI specifications — please **do not open a public GitHub issue**.

Instead, report it privately to: **security@rula.com**

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept (if applicable)
- Any relevant file paths or endpoints

We will acknowledge your report within 5 business days and aim to resolve confirmed vulnerabilities promptly.

## Scope

This repository contains demo and prototype code intended for partner integration reference. It does not contain production credentials, patient data, or PHI. If you find evidence that real credentials or protected health information have been inadvertently committed, please report that immediately via the email above.

## Out of Scope

- Vulnerabilities in third-party dependencies (report those to the upstream project)
- Issues in Rula's production systems — those should be reported through your partner agreement contact or to security@rula.com separately

## Contact

For general partnership or API access questions, contact your Rula Partner Manager or email [epd-partnerships-deals-eng@rula.com](mailto:epd-partnerships-deals-eng@rula.com). Do not use GitHub Issues for production support requests.
